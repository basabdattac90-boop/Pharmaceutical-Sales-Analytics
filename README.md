# Pharmaceutical Sales Analytics

## Project Overview
This project focuses on analysing daily pharmaceutical sales data from 2014 to 2019 to identify sales trends, patterns, category-wise performance and differences in sales across weekdays and weekends.

The project uses Python for data cleaning, exploratory data analysis and visualisation, along with Tableau for interactive dashboard development.

## Dataset
- Source: [Pharma Sales Data – Milan Zdravković (Kaggle)](https://www.kaggle.com/datasets/milanzdravkovic/pharma-sales-data)
- Dataset file used: `salesdaily.csv`
- License: CC BY-NC 4.0 (verify the current licence on the original dataset page).

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Tableau

## Project Workflow
1. Dataset selection and loading
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Descriptive statistical analysis
5. Correlation analysis
6. Data visualisation
7. Interactive Tableau dashboard development
8. Insight generation and recommendations

## Key Analysis
- Total sales by pharmaceutical category
- Monthly and yearly sales trends
- Category-wise monthly sales patterns
- Weekday versus weekend sales distribution
- Monthly sales seasonality
- Correlation between pharmaceutical categories

## Dashboard
An interactive Tableau dashboard was developed to present:
- Category sales by year
- Monthly sales trends
- Annual total pharmaceutical sales volume
- Weekday versus weekend sales distribution

## Repository Structure
- `data/` – Original and cleaned datasets
- `notebooks/` – Jupyter Notebook containing the analysis
- `outputs/charts/` – Exported visualisations
- `dashboard/` – Tableau dashboard workbook

## How to Run the Project
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells sequentially.

## Project Outcomes
The analysis provides insights into pharmaceutical sales performance, category-wise contribution, temporal trends and differences in daily sales patterns.
